# herdr-setup

Обвязка вокруг herdr: роли воркеров, их запуск, права, worktree и связь с
ведущим агентом. Здесь эта обвязка разрабатывается, проверяется и хранится
как исходник; в домашней папке лежат только работающие копии.

Раньше эти задачи решались по месту: правка оберток в `~/.herdr-templates`,
куски текста в репозитории `prompt`, разовые проверки в терминале. Решения
оседали в переписке и в самих файлах, восстановить причину было нельзя.
Отдельный репозиторий нужен, чтобы у настройки был один дом, история и
возможность откатиться.

## Что здесь будет

- Исходники оберток ролей и установщика профилей, сейчас живущие в
  `~/.herdr-templates`.
- Шаблоны запуска из `~/.config/herdr-core/templates`.
- Профили Codex из `~/.codex/*.config.toml` в части, которую задает обвязка.
- Мод, который даст ведущему агенту прямые инструменты запуска и общения с
  воркерами вместо ручных команд `hc`.
- Записи о том, что проверено запуском: гранты Git, worktree, песочница,
  адресация отчетов.

Текст глобальных инструкций остается в `~/data/prompt`: там его собирают под
каждую цель, и `parts/HERDR.md` с `parts/HERDR_COMMON.md` — часть того набора.
Справка по herdr остается навыком `~/data/skills/herdr`. Этот репозиторий не
дублирует ни то, ни другое: он отвечает за обвязку, а не за текст правил.

## Раскладка

Пока пусто: `AGENTS.md` и это описание. Раскладка появится вместе с первым
переносом, тогда же сюда попадет раздел о том, что куда переехало.

## Правила

- Цель переноса: источник здесь, в домашней папке — исполняемые копии, которые
  раскладывает установщик. Пока переезд не закончен, у части файлов источник
  остается на месте; такие файлы перечисляются здесь явно, чтобы не завести
  две правды.
- Проверка настройки — запуск воркера и его отчет, а не чтение конфига.
  Успешный запуск установщика ничего не доказывает.
- Инструкции проекта — этот файл. `CLAUDE.md` в проект не добавлять: при нем
  Claude Code перестает подхватывать `AGENTS.md`.
